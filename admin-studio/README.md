# Lunex Admin Studio

Локальный визуальный редактор версионных контент-пакетов для клиента Godot.

**Это не игровой сервер.** Прогресс игрока, валюты, бой и платежи сюда не пишутся.

```bash
npm install
npm run dev
```

- UI: http://127.0.0.1:5173  
- API: http://127.0.0.1:8787  

Подробности: `../docs/ADMIN_STUDIO.md`.
