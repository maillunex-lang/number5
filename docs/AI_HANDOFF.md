# Передача проекта · Android 0.5.5

Срез от 20 ноября 2026. Исходники клиента, API и Studio синхронизированы с версией VPS. Рабочие документы — [статус](STATUS.md) и [приоритеты с критериями приёмки](ROADMAP.md).

Первый проход на физическом телефоне должен охватить установку APK, гостевой вход, карту, длинные списки, действие «Назад», бой, сворачивание и восстановление. Зафиксировать устройство, версию Android, номер сборки и этап до и после повторного входа.

Для работы над схемой использовать отдельную тестовую БД Lunex. Сравнить player_profiles и колонки авторизации с миграциями репозитория, затем проверить запуск с пустой БД. Работающий VPS и успешный health-check сами по себе этот сценарий не покрывают.

Публичный Web отключён. При изменениях клиента сохранять раздачу Android APK, API и HTTPS CDN. Исторические отчёты прототипа относятся к своим версиям.
