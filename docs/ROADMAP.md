# Lunex AFK - Roadmap
Статус: план, не отчёт о выполненных работах.
Последовательность проектирования: D (документы) -> C (контент) -> A (детальное ТЗ на фундамент) -> реализация после отдельного разрешения.

## Этапы реализации и зависимости
| ID | Этап | Зависимости | Критерий завершения |
|---|---|---|---|
| CORE-01 | Изолированный каркас клиента, сервера, БД, CI | утверждённый GDD, ТЗ A | компоненты запускаются, другие проекты не затронуты |
| UI-02 | Lunex UI Kit и навигация | CORE-01 | основные экраны открываются и масштабируются |
| APK-03 | Первый тестовый APK | CORE-01, базовый UI-02 | установка, запуск, навигация на реальном Android |
| AUTH-04 | Email/пароль, гость, профиль | CORE-01 | повторный вход сохраняет прогресс |
| ART-05 | GLB/спрайты, Blender, атласы | CORE-01, контент C | Idle/Attack/Skill/Hit/Death воспроизводятся корректно |
| BATTLE-06 | Авторитетный автобой 5v5 | AUTH-04, данные героев; ART-05 для визуала | серверный результат корректен, подмена не проходит |
| RPG-07 | Коллекция, развитие, призыв | AUTH-04, BATTLE-06 | улучшения влияют на бой, призыв корректно начисляет |
| WORLD-08 | Кампания 30 этапов, AFK | BATTLE-06, RPG-07, контент C | полный цикл бой -> награда -> развитие |
| PVE-09 | Башня, боссы, подземелья и др. | BATTLE-06, RPG-07 | включённые в MVP режимы имеют правила и награды |
| ADMIN-10 | Админка и визуальная студия | CORE-01; далее по модулям | контент изменяется без прямой правки БД |
| OPT-11 | Качество, загрузка, кеш, CI/CD | игровой цикл, ADMIN-10 | тесты на Android и iPhone/PWA пройдены |
| ALPHA-12 | Закрытая альфа | все обязательные функции MVP | нет блокирующих/критических дефектов |

ADMIN-10 развивается параллельно с игровыми модулями. UI-02, AUTH-04 и ART-05 могут идти параллельно после CORE-01. Первый APK собирается до полного игрового цикла.

## Контрольные версии
- v0.0.1: каркас, интерфейс, первый APK.
- v0.0.2: авторизация, хаб.
- v0.0.3: анимированные герои, тестовый бой.
- v0.0.4: серверный бой, развитие.
- v0.0.5: кампания, награды, AFK.
- v0.0.6: призыв, PvE.
- v0.0.7: админка, пакеты, оптимизация.
- v0.1 Alpha: расширенный MVP.
- v0.2 Beta: расширение социальных и PvP-функций.
- v1.0: публичный релиз после отдельного утверждения.

## Тестовые ворота
1. Smoke: запуск, вход, навигация.
2. Functional: бой, награды, прогресс, призыв.
3. Graphics: атласы, VFX, размеры экранов.
4. Performance: FPS, RAM, загрузка, батарея на Android от 6 ГБ.
5. Network: обрывы, повторные запросы, восстановление.
6. Server: транзакции, параллельные бои, нагрузка.
7. Release: подпись, обновление, откат, iPhone Web/PWA.

## Управление изменениями
Новые решения фиксируются отдельным кодом и обновляют GDD, архитектуру, MVP и дорожную карту согласованно. Не считать целевой набор гильдий, межсерверных функций и монетизации обязательным для v0.1, если он не включён в MVP.md.
