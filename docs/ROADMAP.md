## Реализовано и проверено

- CORE-PG-DEPLOY и OTA-2 работают на VPS. API использует PostgreSQL и отдаёт состояние через HTTPS. CDN публикует пакет 0.9.0.
- H4 реализован в запуске API: при ошибке PostgreSQL в prod процесс завершается. H5 ограничивает тестовые операции окружением test.
- Клиент загружает профиль, кошелёк, коллекцию и отряд. Бой и повторный claim проверены через публичный API.
- Общая тема, навигация четырёх вкладок и обновление OTA проверены в Godot. Подписанный debug APK опубликован; приёмка на устройстве остаётся P0.

## Платформы и закрытая альфа

Публичная Web/PWA-версия отключена по решению владельца. Возврат Web требует отдельного решения. Для закрытой Android-альфы остаются приёмка устройства, воспроизводимые миграции, проверка экономических операций и боевого воспроизведения. Критерии описаны выше.
