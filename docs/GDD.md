# Number5 — Game Design Document (каркас)

> Версия: 0.1 · UI Shell  
> Движок клиента: **Godot 4** · Портрет **1080×1920**  
> Сервер: VPS (позже) · Сюжет / баланс / ассеты — позже

---

## 1. Видение

**Number5** — idle / AFK MMO в духе AFK Arena: коллекция героев, автопрогресс вне игры, PvE-кампания и бои на боковой 2D-сцене с сеткой **5×5**.

Сейчас цель — **каркас клиента**: экраны, навигация, заглушки данных. Механики наполняются итерациями.

---

## 2. Платформы и техника

| Слой | Решение |
|------|---------|
| Клиент | Godot 4, GDScript, `AnimatedSprite2D` для юнитов |
| UI | Портретная раскладка, нижний таб-бар |
| Бой | Вид сбоку, две сетки 5×5 (союзники / враги) |
| Сеть | Позже: REST/WebSocket к VPS |
| Авторизация | Сейчас локальный stub; позже аккаунты на сервере |

---

## 3. Карта экранов

```
Boot → Auth → MainHub
                ├─ Home (AFK + Campaign CTA)
                ├─ Heroes
                ├─ Guild (Overview / Members / Quests)
                ├─ Shop (донат-паки stub)
                └─ More (Chat, Battle sandbox, Logout)
Overlays: Chat, Battle
```

### 3.1 Auth

- Поля username / password, «Enter World», «Continue as Guest».
- Без сервера: любой непустой логин пускает в хаб.

### 3.2 Main Hub chrome

- **TopBar**: ник, уровень, золото, алмазы, кнопка Chat.
- **BottomNav**: Home · Heroes · Guild · Shop · More.

### 3.3 Home

- AFK rewards (claim stub → +gold).
- Campaign progress placeholder.
- CTA **Enter Battle** → overlay Battle.

### 3.4 Heroes

- Список stub-героев (имя, редкость, фракция, уровень, power).
- Детальная карточка по тапу.
- Позже: фильтры, экип, прокачка, AnimatedSprite превью.

### 3.5 Guild

- Вкладки Overview / Members / Quests — текст-заглушки.
- Позже: создание/вступление, рейды, склад гильдии.

### 3.6 Chat (overlay)

- Каналы World / Guild.
- Локальная лента + отправка в stub-хранилище `AppState`.
- Позже: realtime через VPS.

### 3.7 Shop

- Карточки донат-паков с ценой-плейсхолдером.
- Buy → +diamonds (без оплаты).
- Позже: IAP / платёжный шлюз.

### 3.8 Battle (overlay)

- Фон небо/земля (плейсхолдер).
- Две `GridContainer` 5×5; занятые слоты помечены `H` / `E`.
- Start / Flee — без симуляции урона.
- Позже: расстановка, скиллы, `AnimatedSprite2D` в слотах, серверный реплей или клиентская симуляция.

### 3.9 More

- Быстрые ссылки на Chat, Battle sandbox, Logout.

---

## 4. Бой 5×5 (заготовка дизайна)

- Вид **сбоку**: колонки = глубина строя, строки = вертикальные ряды.
- Союзники справа (или слева — зафиксировать при артах); враги напротив.
- В слот позже вешается `AnimatedSprite2D` + HP bar.
- Автобой AFK Arena-стиля: скиллы по кулдауну / энергии (TBD).

## 5. Экономика (stub)

|--------|------------|
| Gold | Прокачка / крафт (позже) |
| Diamonds | Премиум / донат |

## 6. Autoload / данные

- `AppState` — игрок, валюты, heroes[], shop_packs[], chat_messages[].
- `ScreenRouter` — табы и overlays.
- `UIColors` / `UIStyle` — navy + gold тема.

---

## 7. Roadmap (следующие итерации)

1. Серверный auth + профиль на VPS.
2. Настоящие герои (ресурсы + спрайты).
3. Боевая симуляция + анимации.
4. AFK таймер с оффлайн-наградой с сервера.
5. Гильдии и чат realtime.
6. Магазин с реальными платежами.
7. Сюжет кампании и лор.
