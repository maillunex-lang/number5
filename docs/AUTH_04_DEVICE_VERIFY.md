# AUTH-04 — приёмка на устройстве

Критерий ROADMAP: email-регистрация, привязка гостя, истечение/отзыв сессии, смена аккаунта, восстановление после обрыва сети; после смены аккаунта коллекция/профиль с сервера (UI-SYNC-HEROES).

Автоматика (`go test` / Memory): register, dup email, login, link guest, logout revoke, session expiry. Ниже — телефон.

## Перед тестом

1. Свежий APK после merge AUTH-04 (+ деплой API с Memory/PG credentials).
2. Online API/CDN доступны.
3. Записать: модель, Android OS, versionName / versionCode.

## Чеклист (8–12 мин)

| # | Шаг | Ожидание | ✓ |
|---|---|---|---|
| 1 | Экран входа → Регистрация (email + пароль ≥10) | Вход в игру, тип «Зарегистрированный», email в Настройки → Аккаунт | |
| 2 | Выйти → Войти тем же email/паролем | Тот же прогресс (герои/золото), не новый гость | |
| 3 | Выйти → Гость → Настройки → Аккаунт → Привязать email | Успех; тип стал зарегистрированный; герои/кошелёк **те же** (гость сохранён) | |
| 4 | Выйти → логин привязанным email | Тот же прогресс | |
| 5 | Выйти из аккаунта | Возврат на auth; повторный вход по старому токену невозможен (нужен логин) | |
| 6 | Войти → свернуть / выключить сеть 5–10 с → вернуть | Сессия восстанавливается или понятный offline; после сети sync без краша | |
| 7 | Два аккаунта: A → logout → B → проверить героев | Коллекция B, не «призрак» A (UI-SYNC-HEROES) | |
| 8 | (Опц.) Дублирующий email при регистрации | Ошибка, без входа | |

## Не баг

- Memory-only локальный API без PG — credentials работают в CI; prod = Postgres.
- Пароль < 10 символов / битый email — 400.

## После прогона

Владелец: **AUTH-04 device OK** (или FAIL с шагом #).  
Агент закрывает пункт в STATUS/ROADMAP.
